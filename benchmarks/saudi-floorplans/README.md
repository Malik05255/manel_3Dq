# Saudi Floorplan Benchmark

هذا المجلد هو عقد البيانات لاختبار قراءة المخططات السكنية السعودية بشكل قابل للقياس، وليس مجموعة صور تجريبية غير موثقة.

## الهدف

قياس أربعة محاور على مخططات سعودية موسومة يدويًا: أنواع الغرف، الجدران، الأبواب/النوافذ، والأبعاد. كما يسجل الاختبار هل الناتج يجتاز Geometry V3.

## قواعد إدخال البيانات

- لا تضاف أي صورة أو PDF إلا مع حق استخدام واضح أو إذن صاحبها.
- يجب حذف الأسماء وأرقام القطع والهواتف وأي بيانات شخصية غير لازمة.
- يفضل تمثيل مناطق مختلفة: الرياض والوسط، جدة/مكة/المدينة، الشرقية، أبها والمرتفعات، جازان والساحل الجنوبي، والشمال.
- لا تعتبر المخططات المنشورة على الإنترنت مرخصة تلقائيًا لإعادة التوزيع.
- `reference.json` هو الوسم اليدوي المرجعي بنفس بنية FloorPlan المنطقية.
- النتيجة المتوقعة النهائية هي 100 حالة كحد أول، ثم 300، ثم 500. لا يجوز الادعاء بهذه الأعداد قبل وجودها فعليًا في manifest.

## المقاييس

`SaudiPlanBenchmarkEngine` يحسب:

- Room type F1
- Wall F1 ضمن سماحية هندسية نسبية
- Opening F1 حسب النوع والموقع
- Dimension accuracy ضمن 5% أو 12 سم أيهما أكبر
- Geometry V3 pass/fail
- Overall weighted score

## manifest.jsonl

كل سطر يمثل حالة واحدة:

```json
{"id":"riyadh-001","city":"الرياض","region":"central","source":"licensed-private","asset":"assets/riyadh-001.pdf","reference":"labels/riyadh-001.json","floors":2,"notes":"de-identified"}
```

لا يضاف الملف الفعلي إلى المستودع العام إذا كان الترخيص لا يسمح بذلك؛ يمكن للـCI الخاص أو المختبر المحلي تحميل الأصول من مخزن خاص مع الاحتفاظ بالـmanifest والوسوم المسموح بها.
