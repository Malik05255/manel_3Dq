# منزلي HAI

تطبيق Android ذكي لبناء وتعديل المخططات السكنية ثنائية الأبعاد.

## الرؤية
منزلي HAI لا يعامل المخطط كصورة فقط. عند رفع صورة أو PDF يحوّلها إلى تمثيل منظم للغرف والعلاقات والمساحات والثقة في القراءة، ثم يسمح للمستخدم بالتحدث مع «مهندس HAI» لتعديل المخطط مع شرح التنازلات قبل التنفيذ.

## المرحلة الحالية
- شاشة رئيسية: «ابنِ مشروعك» و«حوّل مشروعك إلى 3D».
- داخل «ابنِ مشروعك»: «مشروع جديد» و«تعديل مشروع سابق».
- استيراد صورة/PDF من الهاتف.
- تحويل صفحة PDF الأولى إلى صورة محليًا قبل التحليل.
- اتصال فعلي بأي مزود OpenAI-compatible (الافتراضي OpenRouter) عبر مفتاح المستخدم.
- تحليل بصري منظم للمخطط وإرجاع غرف ومساحات وعلاقات وملاحظات وثقة.
- محرر 2D بصري مبدئي مبني على بيانات Vector normalized.
- محادثة «مهندس HAI» مع سياق المخطط وطلبات التعديل.
- إنشاء مشروع جديد من متطلبات المستخدم وإرجاع مخطط JSON قابل للرسم.

## هوية التحديث
`applicationId = com.manzili.hai`

يجب عدم تغييره مستقبلًا. ولتثبيت النسخة الجديدة فوق القديمة يجب أيضًا استخدام نفس مفتاح التوقيع ورفع `versionCode` فقط.

## إعداد الذكاء الاصطناعي
من داخل التطبيق افتح «إعدادات HAI»، ثم أدخل:
- API endpoint (مثال OpenRouter: `https://openrouter.ai/api/v1/chat/completions`)
- API key
- model id

لا يوجد مفتاح سري داخل المستودع.

## البناء
```bash
./gradlew assembleDebug
```

النسخ الإنتاجية يجب توقيعها بنفس keystore دائمًا حتى تقبل Android التحديث فوق النسخة السابقة.
